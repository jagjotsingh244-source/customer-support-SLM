# Returning an item

## Return window
You can return home and accessories items within 15 days of delivery. Home
items include bedsheets, towels, pillows, cushion covers, kitchenware and
kitchen appliances, fans, lamps and clocks. Accessories include bags, wallets,
belts, caps, sunglasses, phone cases, cables, chargers and adapters.
Electronics have a 7-day return window and must be unopened. Opened electronics
can be returned only if they are faulty (see "Returning electronics").

## When the return window starts
The return window starts on the delivery date of the shipment the item arrived
in. If your order arrived in more than one shipment, on different days, each item
has its own return window, counted from the day its own shipment was delivered.

## Items you cannot return
Some items are marked "Not returnable" on the product page. Once unsealed,
they cannot be returned for a change of mind (see "Items you cannot return").

## Reasons for a return
You can return an item because it is faulty, damaged in transit, the wrong item,
or because you changed your mind.

## Exchanges
We do not offer exchanges. To get a different item, size or colour, return the
one you have within its return window and place a new order.

## How to start a return
Ask Nova or open the order page. Nova checks whether the item is inside its
return window and proposes a return. The return starts only after you confirm
it.

## Pickup
We pick up the item from your delivery address 1–2 days after you confirm the
return. Keep the item in the condition you received it, with all parts.

## Inspection
We inspect the item within 2 days of pickup. If it passes, we send your refund
(see "Refund timing").

## Why a return can be rejected
A return is rejected if it is outside the return window, if the item is marked
"Not returnable" and has been unsealed, if opened electronics are not faulty, or
if the item fails inspection. If an item fails inspection after pickup, we send
it back to you.

## Returning part of an order
You can return one item and keep the rest. You get a refund for the returned
items only (see "Partial refunds").
